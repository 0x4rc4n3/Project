2 Gateway ➔ Crypto Service: POST /package (HTTPS + Bearer API Key). Signs with ML-DSA-65 and splits into 3-of-5 Shamir secret shares.

5 Verifier ➔ Gateway: POST /verify queries ledger anchor, retrieves $\ge 3$ valid shares, and verifies ML-DSA-65 signature.

Cryptographic Security & System Boundaries

1. Zero-Knowledge Key Storage

Private keys are never stored on local disk or environment variables. All signing keypairs are managed dynamically in HashiCorp Vault.

2. Isolated Database Sharding

5 independent SQLite database nodes are maintained (`node_1.db` through `node_5.db`). No single database node contains $>1/n$ shares.

3. Reconstruction-less Verification

Verification performs anchor checking and share integrity validation prior to passing shares to `crypto-service:5001/unpackage`.

4. Immutable Blockchain Audit Ledger

Credential IDs and SHA3-256 data hashes are immutably anchored on Hyperledger Fabric, preventing retroactive tampering.
